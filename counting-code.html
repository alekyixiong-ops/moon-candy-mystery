😈 Make it even harder

  • Use longer words — counting to the 7th letter is harder! 🔢
  • Put the number after the word: sky 3
  • Hide fake lines in between, and read only every 2nd line
  • Use words from a theme (only animals? only food?) so it looks innocent 🕵️
  • Or combine with the shopping list code: number and first letter! 🧠
