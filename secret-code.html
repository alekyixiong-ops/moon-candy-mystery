🔐 The idea in one picture

You need two things: a message and a key word. The key is the secret — it's what unlocks the jumble. 🔑

Three steps:

1️⃣ Write the message in rows under the key.
2️⃣ Number the key's letters in alphabetical order.
3️⃣ Read down the columns in number order — that's your jumble! 🎲

Our example: message MEET ME AT THE MOON, key MOON 😊

💡 See the X at the end? That's filler — we pad the grid so it's a neat rectangle. Powers of the code! (Agents call it “null padding”.) 🤫

🔄 To read it back: do it backwards. Cut the jumble into pieces the size of the grid's height, put them back into the numbered columns, then read left-to-right. That's what my Decode tab does for you.

🧠 Why spies love this code

Some codes work by swapping letters (A→Q, B→Z...). Those are easy to break, because the letters that appear most often are still the common ones — so codebreakers count them. 📊

This code doesn't change letters at all. It moves them around. Every letter is still there — just in the wrong order! So counting letters tells you nothing. 🙈

🔢 And the key space is enormous.
With a 6-letter key there are 720 different orders. With a 10-letter key: over 3 million. And without knowing the key length, a cracker must try every length too!

🔒 The golden rule of codes: the method can be public — it's safe. Only the key must stay secret. That's exactly how the internet keeps your passwords safe today! 🌐

🔥 Real history: spies in World War I and II used jumbles like this, and the famous Enigma machine was a super-powered version. Mathematicians (and a brilliant man named Alan Turing) cracked it — and that helped end the war. You're using the same family of ideas they did. 🎖️
